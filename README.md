# METABOLISM

**生化学がテーマのインクリメンタルゲーム** ― v0.2.2

細胞の中で糖（グルコース）を分解する「解糖系」を動かし、研究を重ねて、代謝のしくみを一つずつ明らかにしていくゲームです。
ブラウザだけで遊べます（インストール・アカウント登録は不要）。スマートフォン・PC の両方に対応しています。

## このバージョンで遊べること
- 解糖系を「準備期・回収期」の全体図で動かし、研究ポイントで細胞を強化する
- 解糖系の内部を解析し、10 の酵素を 1 つずつ同定する
- NAD⁺ が足りなくなる問題に向き合い、乳酸デヒドロゲナーゼ（LDH）で NAD⁺ を再生する
- 細胞の中にたまる乳酸を観察し、輸送体 MCT で乳酸を細胞の外へ運ぶ
- 細胞の外（EXTRACELLULAR）の存在を知る（細胞外環境・細胞間代謝は今後のアップデートで解放予定）
- 乳酸の生成と排出をつり合わせて「第1章 解糖系と発酵」を終える（v0.1.2）
- 進み具合を文字列で書き出し、別の端末・ブラウザで読み込む（v0.1.2）
- PFK-1 が ATP で抑えられ、解糖系の流れが「細胞が ATP を使う速さ」に合わせられるしくみ（実在の調節。v0.2.0）

## 遊び方
1. 「グルコースを入れる」で糖を入れると、解糖系が動いてピルビン酸ができます。
2. ピルビン酸ができるたびに研究ポイント（RP）が入ります。研究タブで細胞を強化しましょう。
3. 画面上の「次の目標」に沿って進めると、新しい仕組みが見つかります。
4. ⓘ や点線の下線がついた言葉をタップすると、説明が開きます。ヘッダの「?」でいつでも遊び方を確認できます。

## 科学的な単純化について
生化学のしくみをもとにしていますが、ゲームにするために単純化しています。
量の単位「u」はゲーム独自の単位で、実際の細胞内の濃度を表すものではありません。反応の速さはゲーム上の値です（平衡定数は教科書の ΔG°′ から計算）。
細胞は「嫌気的条件」（酸素を利用したミトコンドリアでの NADH 再酸化が使えない条件）として扱っています。
詳しくはゲーム内の「詳細」タブ →「このゲームの単純化」をご覧ください。学習のきっかけにはなりますが、教科書や専門書の代わりにはなりません。

## 保存とプライバシー
- 進み具合は、遊んでいるブラウザの保存領域（localStorage）にだけ保存されます。
- サーバーへの送信、アカウント、Cookie、アクセス解析、広告は使っていません。個人情報は集めていません。
- 外部のサーバーからファイル（フォント・ライブラリなど）を読み込みません。
- ブラウザのサイトデータを消すと、進み具合も消えます。別の端末・別のブラウザとは自動では共有されません。
- 詳細タブの「書き出す」で進み具合を文字列にし、移したい先の「読み込む」に貼り付けると引き継げます（v0.1.2）。文字列には進み具合だけが入り、どこにも送信しません。読み込む前の進み具合は「読み込む前に戻す」で1回だけ元に戻せます。

## ローカルで動かす
`public/index.html` をブラウザで開くだけで遊べます。
公開時と同じヘッダーで確かめるときは：
```
python3 dev/tools/serve.py 8787     # http://127.0.0.1:8787/
```

## 検証（開発者向け）
```
node dev/tests/run_tests.js                                  # 計算（化学量論・保存則・非負性・平衡・セーブ移行・経済）
node dev/tests/savecode_tests.js                             # セーブの書き出し・読み込み（v0.1.2）
node dev/tests/v020_tests.js                                 # v0.2.0 の4条件（6 時間の安定性・ATP 需要への応答・保存則・経済）とセーブの互換（約6分）
node dev/tests/text_lint.js                                  # 表示文言・公開前の静的チェック
python3 dev/tests/ui_smoke.py public/index.html              # 画面操作（Playwright と Chromium が必要）
python3 dev/tests/release_check.py http://127.0.0.1:8787/    # 公開時の画面での確認（serve.py を起動してから）
python3 dev/tests/pre_release.py                             # 公開前の自動テストをまとめて実行（必須。1つでも失敗したら公開しない）
python3 dev/tests/version_check.py                           # 版のそろい具合（表示・JS・CHANGELOG・MANIFEST・文書）と public/ の照合
python3 dev/tests/manifest_tests.py                          # MANIFEST の作成・照合と版の検査そのもののテスト
```

公開用ビルドの記録（`docs/MANIFEST_v<版>.sha256`）：
```
python3 dev/tools/make_manifest.py v<版>    # 新しい版の MANIFEST を作る（過去の版は書き換えない）
python3 dev/tools/verify_manifest.py        # public/ を最新の版（SemVer の数値順）の MANIFEST と照合
python3 dev/tools/verify_manifest.py v<版>  # 版を指定して照合
```
`?debug=1` を付けて開くと、画面テスト用の窓口と計算の健全性の表示が有効になります（公開時の画面には出ません）。
