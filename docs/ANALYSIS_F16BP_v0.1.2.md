# F1,6BP が溜まり続ける原因の分析（v0.1.2 時点の計算）

v0.2.0（PFK-1・PK の調節）の前提作業。計算は v0.1.1 と同じ。再現：`node dev/tools/f16bp_analysis.js`（約4分）。

## 結論

**主因は「ATP の消費（細胞の仕事 `atpase`）が、グルコースの取り込みが生む ATP を使い切れないこと」による ADP の不足**。回収期（PGK・PK）は ADP がないと進めないので、ADP が戻ってくる速さで頭打ちになる。一方、準備期は ATP が余っているうえ PFK-1 に調節がないので、取り込んだグルコースをすべて F1,6BP まで送り続ける。その差がアルドラーゼの手前に溜まる。

アルドラーゼ・PK・回収期の酵素の量（Vmax）は原因ではない（下の比較実験で、2倍にしても溜まる速さは変わらない）。

## 流束の単位（アルドラーゼ流束と三炭糖流束の区別）

アルドラーゼは F1,6BP（六炭糖）1分子を DHAP＋GAP（三炭糖）2分子に分ける。そのため、この資料では次の2つを分けて書く。

- **アルドラーゼ流束 J_ald**：F1,6BP が分解される正味の速さ。単位は **F1,6BP 分子/秒**（グルコース換算と同じ）。
- **三炭糖流束 J_tri**：アルドラーゼの後（GAPDH・PGK・…・PK）を流れる三炭糖の速さ。単位は **三炭糖分子/秒**。定常では J_tri ＝ 2 × J_ald。

F1,6BP の収支は「PFK-1 の流束 − J_ald」（F1,6BP 分子/秒）で決まり、ATP・ADP の収支は J_tri（PGK と PK で1分子ずつ）で決まる。下の表と式では、どちらの単位かを毎回書く（ゲームの u はどちらも「分子1個＝1 u」として数える）。

## しくみ

1. 回収期で ADP を ATP に変えるには ADP が要る。ADP が戻ってくるのは、HK・PFK-1・atpase が ATP を使ったときだけ。
2. したがって三炭糖流束 J_tri（三炭糖/秒）は、2 J_tri（PGK と PK がつくる ATP）＝ 2 J_glut（HK と PFK-1 が使う ATP）＋ A（atpase）で決まる。J_tri ＝ J_glut ＋ A / 2。
3. 取り込んだ分をすべて流すには J_tri ＝ 2 J_glut（三炭糖/秒）が要る。**A < 2 J_glut**（ATP の消費の能力が、グルコース1分子あたり正味2の ATP を使い切れない）なら、不足は 2 J_glut − J_tri ＝ J_glut − A/2 三炭糖/秒。これを F1,6BP に直すと (J_glut − A/2) / 2 ＝ (2 J_glut − A) / 4 F1,6BP/秒 ずつ溜まる（アルドラーゼ流束 J_ald ＝ J_tri / 2 ＝ J_glut/2 ＋ A/4）。
   - 実測：三炭糖の不足 4.000 − 2.683/2 ＝ 2.66 三炭糖/秒 ＝ **1.33 F1,6BP/秒**。測った ＋1.32 F1,6BP/秒と一致する。J_ald の予測 2.00 ＋ 0.67 ＝ 2.67 F1,6BP/秒も測った 2.68 と一致する。
4. 溜まる場所がアルドラーゼの手前になるのは、アルドラーゼが熱力学的に逆向きに傾いた反応（ΔG°′ ＝ ＋23.8 kJ/mol）だから。回収期が詰まって GAP・DHAP が増えると、平衡を保つために F1,6BP がそれ以上に増える（Q/K ≈ 0.99 のまま）。
5. LDH を得る前は NAD⁺ が先に尽きて回収期が止まるので、この現象は目立たない。LDH で NAD⁺ が再生されるようになると、ADP の不足だけが残って現れる。

| 変えたこと | F1,6BP の増え方（F1,6BP/秒） | 読み取れること |
| --- | --- | --- |
| 変更なし | ＋1.319 | 基準 |
| ATP の消費の Vmax ×2 | ＋0.653 | 消費を増やすと減る（式どおり (2×4 − 5.37)/4 ≈ 0.66） |
| ATP の消費の Vmax ×4 | **−0.660**（溜まった分が減っていく） | A ＞ 2 J_glut で解消 |
| PK の Vmax ×2 | ＋1.318 | **PK を速めても変わらない**（PK は ADP 待ちで、酵素の量は上限ではない） |
| アルドラーゼの Vmax ×2 | ＋1.319 | 変わらない（平衡に近く、酵素の量は上限ではない） |
| 回収期 5 酵素の Vmax ×2 | ＋1.318 | 変わらない |

## v0.2.0 への示唆

- **PK の活性化（F1,6BP によるフィードフォワード）だけでは解消しない**。PK は ADP 不足で止まっているので、Vmax を上げても流束は増えない。
- 現象の根は「取り込み（定速）と ATP の需要の不一致」で、実際の細胞でこれを合わせているのが PFK-1 の ATP による阻害（AMP・ADP による活性化）である。ATP/ADP がほぼ 99/1 になっているので、PFK-1 の調節の信号はモデルの中に既にある。
- PFK-1 を抑えると、F6P・G6P が増え、G6P が HK を抑える（実装済み）。しかし GLUT は定速なので、今度は**細胞内のグルコースが溜まり続ける**と予想される。v0.2.0 では、GLUT にも細胞内のグルコースが増えると取り込みが減る仕組み（例：細胞内のグルコースによる飽和・阻害、または外のグルコースを一定とした可逆の輸送）を合わせて入れ、F1,6BP・G6P・F6P・細胞内グルコースの長時間の推移で確かめる必要がある。
