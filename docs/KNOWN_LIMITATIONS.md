# 既知の制約（v0.1.0）

## 保存
- 進み具合はブラウザの localStorage にだけ保存される。サイトデータの削除、ブラウザの容量整理、プライベートブラウズを閉じることで消える。
- 端末・ブラウザ間で引き継ぐ手段（書き出し・読み込み）はまだない。
- 保存はサイトの住所（オリジン）ごと。Cloudflare Pages のプレビュー用 URL（`xxxx.metabolism.pages.dev` など）と本番 URL では、別々の保存になる。公開後に独自ドメインへ移すと、それまでの保存は引き継がれない。
- 保存できない環境では、遊べるが保存されない（「今すぐ保存」で「この環境では保存できません」と表示）。その場合、遊び方は開くたびに表示される。
- 不在時の進行は最大2時間分。

## 表示・操作
- 縦向きのスマートフォンを基準に作っている。横向きのスマートフォンでは、下の投与ボタンとタブが画面の多くを占める（ヘッダは固定しないようにした）。
- PC では中央の幅 560px の列に表示される（広い画面でも広がらない）。
- 文字の大きさはブラウザの設定に従う。読み上げソフトへの対応は最低限（図は `role="img"` と説明のみ）。
- 確認のダイアログ（「新しい細胞で再開」「すべて最初から」）はブラウザ標準のものを使っている。

## ゲーム内容
- 細胞外環境・細胞間代謝、ミトコンドリア（TCA 回路・電子伝達系）は未実装（予告のみ）。最後の目標は「NADH を NAD⁺ に戻す方法は、乳酸の生成だけではない」で止まる。
- LDH 獲得後、1つの細胞で長く遊ぶと、PFK-1 の調節を省略しているため中間体（F1,6BP）が溜まり続ける（画面にもそう説明が出る）。状態表示ではこの注意が乳酸のメッセージより優先されることがある。
- 量の単位 u はゲーム独自の単位で、実際の濃度を表さない。NAD⁺ や乳酸の量は実際の細胞内の値よりずっと大きい。
- MCT の強化は研究ポイントを増やさない（細胞内の乳酸の落ち着く量を下げるだけ。上限 Lv5）。
- 初めから MCT 獲得までは、標準的な遊び方で約50分（自動プレイでの目安）。

## 検証の範囲
- 画面の確認はヘッドレスの Chromium（Playwright）で行った。Safari（iOS）・Firefox・実機での確認は、公開前に人の手で行う必要がある（docs/DEPLOY.md のチェックリスト）。
- 初回から MCT 獲得までの進行は、計算層の自動プレイ（tools/economy.js の方針、90分）で確認した。ブラウザで 50 分間を通しで遊ぶ確認は自動では行っていない（各段階は開発版のセーブデータを読み込んで画面で確認）。
